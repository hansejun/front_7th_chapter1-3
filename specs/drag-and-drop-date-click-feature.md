# 기능 명세서: 드래그 앤 드롭 및 날짜 클릭 일정 생성

**작성일**: 2025-11-02
**프로젝트**: Calendar Event Management Application
**버전**: 1.0.0

---

## 1. 개요

본 명세서는 캘린더 애플리케이션에 두 가지 사용자 편의 기능을 추가하는 것을 목적으로 합니다:

1. **드래그 앤 드롭을 통한 일정 날짜 변경**
2. **날짜 클릭을 통한 일정 생성 폼 날짜 자동 입력**

두 기능 모두 기존 아키텍처와 패턴을 최대한 활용하며, 사용자 경험 개선에 초점을 맞춥니다.

---

## 2. Feature 1: 드래그 앤 드롭을 통한 일정 날짜 변경

### 2.1 기능 설명

사용자가 캘린더 뷰(Week/Month)에서 일정을 드래그하여 다른 날짜로 이동시킬 수 있는 기능입니다.

### 2.2 기술 스택

- **라이브러리**: `@dnd-kit/core` (현재 미설치, 설치 필요)
- **지원 뷰**: Week View, Month View 모두 지원

### 2.3 상세 요구사항

#### 2.3.1 드래그 가능한 일정

- **일반 일정**: 드래그 가능
- **반복 일정**: 드래그 **불가능** (`event.repeat.type !== 'none'` 조건으로 판별)

#### 2.3.2 드래그 동작

- 사용자가 일정 카드/칩을 클릭하여 드래그 시작
- 드래그 중 **시각적 피드백** 제공:
  - 드래그 중인 일정: 하이라이트 표시 (예: 투명도 조정, 테두리 강조)
  - 드롭 가능한 영역: 강조 표시
  - 드롭 불가능한 영역 (겹침 발생 시): **붉은색 시각적 피드백**

#### 2.3.3 날짜 변경 로직

- **변경되는 값**: `date` 필드만 변경
- **유지되는 값**: `startTime`, `endTime`, 기타 모든 필드는 기존 값 유지
- **예시**:
  - 원본 일정: `2025-11-05, 10:00-11:00`
  - 드롭 후: `2025-11-08, 10:00-11:00` (날짜만 변경)

#### 2.3.4 겹침 처리 로직

##### 드롭 **전** (드래그 중)

- `findOverlappingEvents` 유틸리티를 활용하여 실시간 겹침 검사
- 겹치는 일정 존재 시:
  - 드롭 **불가능**한 상태로 표시
  - 드롭 영역을 **붉은색**으로 시각적 피드백
  - 사용자가 드롭 시도 시: 드롭 실행 안 됨

##### 드롭 **후** (드롭 실행 시)

- 드롭 가능한 상태에서 드롭 시에도 최종 검증 수행
- 겹치는 일정 존재 시:
  - 기존 겹침 경고 다이얼로그 재사용 (`isOverlapDialogOpen` 상태 활용)
  - 사용자에게 "계속 진행" 또는 "취소" 선택권 제공
  - "계속 진행" 선택 시: 서버 업데이트 진행

##### 드롭 불가능 상태에서 드롭 시도

- 겹침으로 인해 드롭이 불가능한 상태에서도 사용자가 드롭 시도 시:
  - 경고 다이얼로그 표시
  - 사용자가 직접 시간을 수정하도록 안내

#### 2.3.5 저장 시점

- **드롭 즉시 서버 업데이트**: 드롭이 성공적으로 완료되면 즉시 `PUT /api/events/:id` 호출
- **기존 `saveEvent` 함수 재사용**: `useEventOperations` 훅의 `saveEvent` 활용
- **에러 처리**: 서버 업데이트 실패 시 원래 날짜로 롤백, 스낵바로 에러 메시지 표시

#### 2.3.6 사용자 피드백

- 드래그 시작: 일정 하이라이트
- 드래그 중: 드롭 가능/불가능 영역 시각적 표시
- 드롭 성공: 스낵바로 "일정이 수정되었습니다" 메시지 (기존 패턴)
- 드롭 실패: 스낵바로 "일정 수정 실패" 메시지

### 2.4 제약사항

- 반복 일정은 드래그 불가능
- 날짜만 변경 가능 (시간대는 기존 시간 유지)
- Week/Month 뷰 모두에서 동일하게 동작

### 2.5 기존 코드베이스 패턴 활용

- **겹침 감지**: `findOverlappingEvents` 유틸리티 재사용
- **다이얼로그**: 기존 `isOverlapDialogOpen` 상태 및 Dialog 컴포넌트 재사용
- **일정 업데이트**: `useEventOperations`의 `saveEvent` 함수 재사용
- **에러 처리**: 기존 `enqueueSnackbar` 패턴 재사용

## 3. Feature 2: 날짜 클릭으로 일정 생성 폼 날짜 자동 입력

### 3.1 기능 설명

사용자가 캘린더의 특정 날짜 셀을 클릭하면, 왼쪽 일정 추가 폼의 "날짜" 필드에 클릭한 날짜가 자동으로 입력되는 기능입니다.

### 3.2 상세 요구사항

#### 3.2.1 동작 조건

- **지원 뷰**: Week View, Month View 모두 지원
- **클릭 대상**: 날짜 셀의 **빈 공간** 클릭 시만 동작
- **이벤트 카드/칩 클릭 시**: 동작하지 않음 (기존 동작 유지)

#### 3.2.2 "빈 공간" 정의

- 날짜 셀 내부에서 이벤트 카드/칩을 클릭하지 않은 경우
- **구현 방법**: 이벤트 카드/칩에 `onClick` 핸들러 추가 후 `event.stopPropagation()` 호출
  - 이벤트 카드 클릭 시: 이벤트 전파 중단 (날짜 셀 클릭 이벤트 발생 안 함)
  - 빈 공간 클릭 시: 날짜 셀의 `onClick` 핸들러만 실행

#### 3.2.3 날짜 입력 로직

- 클릭한 날짜를 `YYYY-MM-DD` 형식으로 변환
- `useEventForm` 훅의 `setDate` 함수 호출하여 날짜 필드 업데이트
- **시간 필드는 변경하지 않음**: `startTime`, `endTime`은 기존 값 유지 (기본값 또는 사용자가 입력한 값)

#### 3.2.4 포커스 동작

- **포커스 이동 없음**: 날짜 클릭 후 폼의 특정 필드로 포커스 이동하지 않음
- 사용자가 직접 원하는 필드에 입력 가능

#### 3.2.5 이벤트가 있는 셀 처리

- 이벤트가 있는 셀이라도 **빈 공간** 클릭 시: 날짜 입력 동작
- 이벤트 카드/칩 클릭 시: 기존 동작 유지 (아무 동작 안 함)

### 3.3 제약사항

- 날짜만 입력, 시간은 기본값 유지
- 포커스 이동 없음
- 이벤트 카드 클릭과 날짜 셀 클릭 구분 필수

### 3.4 기존 코드베이스 패턴 활용

- **날짜 설정**: `useEventForm`의 `setDate` 함수 재사용
- **날짜 포맷**: `formatDate` 유틸리티 활용
- **이벤트 전파 제어**: React의 `stopPropagation` 활용
